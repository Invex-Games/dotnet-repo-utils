Invex .NET Repo Utils

Invex.RepoUtils bundles the tooling the Invex team uses to keep its .NET repositories consistent, well-versioned and safe to release: a Roslyn analyzer that makes every public API exposure deliberate, a test utility that snapshots the public API surface, and an Atom build module that turns those snapshots into CI checks and automates PR and package housekeeping.

Package What it does
